# MadLease

MadLease is a map-based web app for finding subleases around Madison, built for CS571 (Fall 2026). Users can browse available subleases on a map, filter them, and post their own. The site has three pages: a landing page, a main browse interface with listings beside a map, and a profile page showing a user's info and posted subleases.

## Running locally

```
npm install
npm run dev
```
